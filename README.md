## 👾 Sobre Mim

Sou uma **Desenvolvedora Fullstack** e estudante de Ciência da Computação apaixonada por construir produtos digitais que os usuários amam. Acredito no poder do bom design aliado a um código limpo para resolver problemas reais e tornar o dia a dia das pessoas mais simples e acessível.

Sempre fui fascinada pela intersecção entre criatividade e tecnologia. Quando não estou programando, você me encontra explorando tendências de design de marcas, desenhando, jogando, desenvolvendo jogos ou até mesmo usando Ciência de Dados para analisar a performance no automobilismo. 

Estou sempre empolgada para trabalhar em projetos que me desafiam a crescer e aprender algo novo.
